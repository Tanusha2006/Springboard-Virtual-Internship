# Technology Stack

The following tools are planned for developing the AI Response Validation System.

| Technology | How it will be used |
|---|---|
| Python | Main language used to develop the system. |
| Streamlit | To build the user interface. |
| FastAPI | To connect the interface with the backend. |
| Hugging Face Datasets | To access datasets like TruthfulQA and SQuAD. |
| Sentence Transformers | To convert text into embeddings. |
| ChromaDB | To store embeddings and find relevant information. |
| RAGAS | To evaluate response quality and RAG performance. |
| TruLens | To check and monitor evaluation results. |
| Git & GitHub | To manage code and track project changes. |

## Purpose of the Technologies

Python will be used for the main development. Streamlit and FastAPI will handle the interface and backend.

Sentence Transformers and ChromaDB will help find relevant reference information. Hugging Face datasets will provide sample data for testing. RAGAS and TruLens will be explored to evaluate the system.
